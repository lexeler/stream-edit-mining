# Оконная модель (первый заход)

Цель: на входе только видео стрима, на выходе готовый монтажный лист.
Длину выпуска модель выбирает сама, подсказок нет.

Материал — уличные IRL-стримы по 2–4,5 часа. Монтажёр делает из каждого
выпуск примерно на час. Есть семь пар «стрим + монтажный лист из проекта
Premiere»: шесть обучающих, слот 2 отложен как честный тест.

## Итог на честном тесте (слот 2)

Стрим 172 мин → модель сделала выпуск на **62 мин** (у монтажёра 68),
длину выбрала сама. Совпало 33 минуты.

    dataset/pipeline.py, pipeline2.py      стрим -> лента элементов, 28 признаков
    dataset/frames.py                      кадры 2 к/с + движение, яркость, смена плана
    dataset/clip_feat.py                   CLIP: теги кадра и визуальный застой
    dataset/audio_feat.py                  CLAP: теги звука; WavLM x-вектор
    dataset/prosody.py                     высота голоса и её динамика
    dataset/surprisal.py                   неожиданность речи под языковой моделью
    window_model/semantic.py               векторы e5 для текста вокруг элемента
    window_model/text_tags.py              22 смысловые метки текста поверх e5
    window_model/clip_pca.py, clip_tags.py сжатие векторов кадра, 64 тега
    window_model/novelty.py                новизна: было ли такое раньше в эфире
    window_model/llm_judge.py              Qwen2.5-7B, 10 описательных вопросов
    window_model/icl.py                    оценка по примерам в подсказке
    window_model/windows.py                сборка окон, кэш, блоки признаков
    window_model/cross_validate.py         обучение и проверка по одному слоту
    window_model/train_predict.py          итог: обучение -> монтажный лист
    window_model/clean_stream.py           чистка: убрать мусор, отдать остальное
    window_model/assemble.py               правила выпуска -> список отрезков
    window_model/render.py                 рендер видео по монтажному листу

Диагностика лежит в `window_model/diagnostics/`: `structure.py` (из чего
состоит монтаж), `micro.py` (что режут внутри сцен), `shape.py` (форма
монтажа во времени), `systematic_errors.py` (где модель ошибается),
`learning_curve.py` (сколько нужно стримов), `importance.py` (на что
смотрит модель), `boundary_control.py` (контроль к постановке «ищем склейки»).

## Инварианты постановки

1. **Границы элементов считаются только по звуку.** Иначе они выдают ответ.
2. **Лента сплошная**: конец элемента = начало следующего.
3. **Слот 2 — тест**, вскрывается в самом конце, на нём не обучаемся.
4. **Длительность выпуска не подсказывается.**
5. **Совпадение не поднимается укорачиванием выпуска.**

## Ключевые цифры

| Что | Значение |
|---|---|
| Данных | 6 обучающих слотов, 215 тыс. элементов |

## Грабли

- IoU и F1 хвалят того, кто оставляет больше. Сравнивать модели только
  при сопоставимой доле оставленного.
- **F1 слеп к рванине.** Гладкость нарезки задаётся при сборке.
- **Допуск по времени обманывает**: при ±20 с случайный отбор тоже даёт
  0,618. Всегда считать контроль.
- Перекрёстная проверка завышает прибавку над случайным примерно вдвое.
- CLAP требует звук 48 кГц, WavLM — 16 кГц.
- Фильтр `select` в ffmpeg не тянет сотни отрезков: резать по одному
  и склеивать (`window_model/render.py`).
